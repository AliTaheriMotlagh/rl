Q-Learning: یاد گرفتن ارزش هر کار

یک ربات در یک هزارتو است و هیچ چیز نمی‌داند: نه نقشه را، نه جای گنج را، نه جای تله‌ها را. فقط کار می‌کند و پاداش می‌گیرد. می‌خواهیم ببینیم چطور با چند خط ریاضی کوتاه‌ترین راه را پیدا می‌کند.

۱.ایده: به هر «حالت + کنش» یک نمره بده

فرض کن یک جدول داری که برای هر خانه و هر جهت می‌گوید: «اگر اینجا باشم و این کار را بکنم، و بعد از آن بهترین بازی را بکنم، روی هم چقدر پاداش می‌گیرم؟» اسم این عدد Q(s, a) است (Q از Quality یعنی کیفیت).

اگر این جدول را داشته باشیم بازی کردن ساده است: در هر خانه کاری را بکن که Q بیشتری دارد. مشکل این است که جدول را نداریم و باید یادش بگیریم.

معادلهٔ بلمن: قلب RL

کلید کار این مشاهده است که ارزش کار الان = پاداش فوری + ارزش (تخفیف‌خوردهٔ) بهترین کار در خانهٔ بعدی:

Q(s, a) = r + γ · maxa' Q(s', a')

ما Q را نمی‌دانیم ولی می‌توانیم آن را کم‌کم به سمت این هدف هل بدهیم. به این قانون به‌روزرسانی Q-Learning می‌گویند:

Q(s,a) ← Q(s,a) + α · [ r + γ·max Q(s',·) − Q(s,a) ]
  • α (نرخ یادگیری): هر بار چقدر به سمت هدف جدید حرکت کنیم. اگر خیلی بزرگ باشد عدد ناپایدار می‌شود و اگر خیلی کوچک باشد یادگیری کند می‌شود.
  • γ (تخفیف): آینده چقدر مهم است (درس ۱).
  • به عبارت داخل کروشه خطای TD (Temporal Difference) می‌گویند: فاصلهٔ بین «چیزی که فکر می‌کردم» و «چیزی که الان فهمیدم».

کاوش در برابر بهره‌برداری (ε-greedy)

اگر ربات همیشه بهترین کاری را بکند که فعلاً می‌شناسد، شاید هرگز راه بهتر را کشف نکند. پس با احتمال ε یک کار تصادفی انجام می‌دهد (کاوش) و بقیهٔ وقت بهترین کار را (بهره‌برداری).

۲.آزمایشگاه: هزارتو

هر خانه به ۴ مثلث تقسیم شده که هر کدام Q یکی از جهت‌هاست (سبز یعنی خوب و قرمز یعنی بد). فلش نشان می‌دهد ربات الان کدام جهت را بهترین می‌داند. روی خانه‌ها کلیک کن تا دیوار، تله یا گنج بگذاری. با کلیک راست جای شروع عوض می‌شود.

بازده هر اپیزود

۳.چه چیزی دیدی؟

  • ارزش از گنج به عقب پخش می‌شود. اول فقط خانهٔ کنار گنج سبز می‌شود. بعد خانهٔ کنار آن، و همین‌طور ادامه پیدا می‌کند. دلیلش این است که هر به‌روزرسانی فقط یک قدم به عقب نگاه می‌کند (max Q(s')).
  • خانه‌های دورتر کم‌رنگ‌ترند، چون هر قدم ضرب در γ می‌شود. اگر γ را کم کنی، ربات «کوته‌بین» می‌شود.
  • کنار تله‌ها مثلثی که رو به تله است قرمز است، ولی بقیهٔ جهت‌های همان خانه ممکن است سبز باشند.
  • با «لغزندگی» زمین یخ‌زده می‌شود و گاهی ربات به جهت تصادفی سر می‌خورد. ببین ربات یاد می‌گیرد از کنار تله‌ها با فاصله رد شود، حتی اگر راهش طولانی‌تر شود.

۴.کد واقعی

کل الگوریتم همین است، و همین چند خط موتور همهٔ کارهایی است که بالا دیدی:

function qStep() {
  const s = stateIndex(pos);
  const a = Math.random() < epsilon ? randomAction() : argmax(Q[s]);   // ε-greedy
  const { next, reward, done } = world.move(pos, a);                   // environment
  const target = reward + (done ? 0 : gamma * max(Q[stateIndex(next)])); // Bellman
  Q[s][a] += alpha * (target - Q[s][a]);                               // learn
  pos = done ? start : next;
}

۵.تمرین

  1. γ را روی ۰.۵ بگذار، Q را پاک کن و دوباره آموزش بده. خانه‌های دور از گنج چه رنگی می‌شوند؟ ربات هنوز به گنج می‌رسد؟
  2. پاداش هر قدم را صفر کن. ربات هنوز کوتاه‌ترین راه را انتخاب می‌کند؟ (راهنما: γ هم کار جریمهٔ قدم را می‌کند. چرا؟)
  3. ε را صفر کن و Q را پاک کن. چرا ربات گیر می‌کند یا خیلی کند یاد می‌گیرد؟
  4. با دیوار یک هزارتوی سخت بساز و ببین چند اپیزود طول می‌کشد تا حلش کند.
